# Bot City — Status (Mockup)

ไอเดียที่ 2 สำหรับ **my-life-AI_dashboard** ของเก้า — แดชบอร์ดสถานะบอทแบบเมืองไอโซเมตริก 3D

## เปิดดู

```bash
# วิธีที่ 1 — เปิดไฟล์ตรงๆ
xdg-open index.html   # หรือดับเบิลคลิก / ลากเข้าเบราว์เซอร์

# วิธีที่ 2 — static server (แนะนำ ถ้าฟอนต์ CDN ติด CORS บน file://)
python3 -m http.server 8877
# แล้วเปิด http://127.0.0.1:8877/
```

ต้องการเน็ตเล็กน้อยเพื่อโหลดฟอนต์ Google (IBM Plex Sans Thai) — ที่เหลือเป็นไฟล์เดียว ไม่มี build
