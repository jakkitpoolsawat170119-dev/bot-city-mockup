# Bot City — สถานะ (Mockup)

แดชบอร์ดสถานะทีมบอทของเก้า · **อวตารบล็อกสไตล์เกม (Roblox-like)** บนลานไอโซเมตริก

**Live:** https://jakkitpoolsawat170119-dev.github.io/bot-city-mockup/

## เปิดดู local

```bash
python3 -m http.server 8877
# http://127.0.0.1:8877/
```

หรือเปิด `index.html` ในเบราว์เซอร์ (ต้องการเน็ตเล็กน้อยสำหรับฟอนต์ Google)
